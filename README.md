# 12 - NDA概要作成ツール

**ビルド日**: 2026-11-03
**カテゴリ**: practical
**slug**: nda-brief-creator

## 概要
秘密保持契約（NDA）の要点（当事者・期間・対象情報・義務・例外・準拠法）を入力してMarkdown形式のNDA概要をリアルタイムプレビュー付きで出力するSPA。

## 機能
- 開示者・受領者の入力
- 契約期間（開始日・終了日）の日付入力
- 秘密情報の定義テキストエリア
- 使用目的テキストエリア
- 義務事項テキストエリア
- 例外事項テキストエリア
- 準拠法・管轄裁判所の入力
- リアルタイムMarkdownプレビュー（右カラム）
- 日本語/English切替ボタン（出力言語を切り替え）
- コピーボタンでMarkdownをクリップボードへ
- localStorage自動保存（最後の入力内容を保持）
